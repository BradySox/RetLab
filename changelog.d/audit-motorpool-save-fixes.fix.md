* **[Flight Planning]** Take Off no longer discards dragged or inserted waypoints on a package aimed at a motorpool depot. Only the list of parked vehicles on the plan is updated, and only when it changed.
* **[Campaign]** A motorpool depot belongs to the nearest land base from the start of a new game. It used to change owner on the first reload or capture; Abchazian Blitz's two depots near Sukhumi were affected.
* **[Saves]** An old save holding a transfer order filed under the wrong side loads; the order is given to the side that holds it. It used to be reported as an incompatible save.
