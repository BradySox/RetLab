### B248 — HQ requests lean on IADS nodes, then strike targets · §112 · ☐ UNTESTED

**What changed (2026-10-18):** within each difficulty tier, the request picks a kind first:
IADS nodes 3 in 6, strike targets 2 in 6, everything else 1 in 6, among the kinds the tier
holds. IADS nodes are EWRs, plus command posts, comms towers and power stations the advanced
IADS network wires to a site. SAM sites count as "everything else". Unit tests pin the odds;
what a real campaign's pools hold is not tested.

**Pass:** a campaign with the advanced IADS network and HQ requests ticked, over 3 or more turns.

- Most requests are EWRs, wired command posts, comms or power, or strike targets (factories,
  fuel, ammo, missile sites).
- SAM sites, armor and ships still turn up now and then.
- In a campaign without the advanced network, a command post, comms tower or power station
  can still be requested, as a strike target.

**Fail signature:** turn after turn of armor groups or SAM sites while EWRs or strike targets
sit unrequested in the same tier; a request on a site hidden on blue's map.
