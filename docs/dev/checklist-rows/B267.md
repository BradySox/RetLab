the GPU again. On Take off the map's web view is destroyed and a note shows in its place;
a new map is built when the mission ends (Accept results or Abort). Before: `python.exe` held 3,981 MB of
dedicated VRAM mid-mission with the map only hidden (#1354).

**Pass:** restart the app. The map pans and zooms smoothly. In Task Manager, Details tab,
add the "Dedicated GPU memory" column. Note `python.exe` with the map open, then Take off:
mid-mission `python.exe` drops to a few hundred MB. After debrief the map comes back and
shows the new turn.

**Fail signature:** mid-mission `python.exe` still holds GBs of dedicated GPU memory (the
GPU thread keeps it after the view is gone; next step is a software-rendering setting); the
map stays on the note after Accept results or Abort; the rebuilt map is blank.
