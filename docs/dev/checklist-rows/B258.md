### B258 — The AWACS runs the package on SRS · §117 package controller · ☐ UNTESTED

**What changed (2026-10-20):** a RetLab Features setting, AWACS package controller (live
SRS voice), off by default. The blue AWACS speaks on the player package's frequency through
SRS External Audio, and shows each call as text.

**Pass:** tick the setting, generate a mission with a player strike package that has SEAD,
run the SRS server and connect. F10 > AWACS > Check in: a male voice on the package
frequency gives radar contact, the hold angels and the push time. At the push time: "push,
push". Leave the SEAD on the ground once: two holds of 3 minutes, then an abort. Fly the
strike: "all strikers egressed, RTB" once clear of the target. Note any stutter on each call.

**Fail signature:** no voice but text appears (check the External Audio folder setting);
nothing at all (no blue AWACS alive, or the setting off); a call on the wrong frequency; a
push or egress call that never comes; a visible freeze on each call.
