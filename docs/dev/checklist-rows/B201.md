### B201 — An outside AI reads red's turn and its findings check out in the game · §109 · ☐ UNTESTED

**Try:** any campaign at the planning screen. Developer tools > Copy AI connect link, paste it to Claude Code on the same PC, and say "review the turn". ~15 min.

**Pass:** the AI fetches `/start` and `/howtoplay` with the token, then reads `turn_context`, `packages` and `map/image` without errors. Its report quotes values (a package index, a TOT, a squadron's `flyable`) that match what the game shows for that package or base. A request with `?side=blue` comes back 403.

**Fail signature:** a 403 with the copied link (token not accepted); a 500 on any read (a view breaks on this campaign's data: note the endpoint and the campaign); the map picture blank or placed wrong; a reported value that the game window contradicts.
