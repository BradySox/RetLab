### B231 — HQ requests drawn, shown and closed · §112 · ☐ UNTESTED

**Pass:** start a new campaign (the setting is on for new games), plan turn 1 with the
auto-planner on, fly one request's target, then pass the turn.

- The map's status bar has an HQ REQUESTS chip with up to three rows: easy, mid and hard,
  each with 2 to 5 turns left and a why-it-matters line.
- None of the three is the target of a package in the ATO when the turn opened.
- Each is ringed in gold on the map; the HQ requests layer turns the rings off.
- The target panel of a requested site has an HQ request row.
- A flight sent against one has `HQ REQUEST  <tier>, N turns left` under the BLUF task line.
- After the mission destroys it, the SITREP has `HQ request done: <name> (<tier>)`, and the
  next turn draws a new request for that tier.
- Buying a SAM mid-turn (a blue re-plan) leaves the turn's requests unchanged.
- An old save loads with the setting off and no chip.

**Fail signature:** no chip on a new game; a requested target that already had a package;
a request on a site hidden on the map; the list changing mid-turn; a destroyed request with
no SITREP line, or still listed next turn.
