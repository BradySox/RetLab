### B328 — JTAC drones lase through MOOSE AUTOLASE · MIST removal step 3a · ☐ UNTESTED

Any mission with a JTAC drone and the CTLD plugin's **JTAC autolases targets** ticked. Fly
to the JTAC's area with a laser-guided weapon.

**Pass:**
- `dcs.log` has `DCSRetribution|JTAC - <group> lases on <code> (blue)` and no
  `AUTOLASE setup failed`.
- The JTAC reports a lased target in an on-screen message, on the code shown on the
  kneeboard (1113 with **JTAC uses the FC3 laser code (1113)** ticked).
- A weapon guided on that code hits the target; the JTAC moves to another vehicle after a
  kill. Infantry is never lased.
- With **JTAC marks targets with smoke** ticked, the target is smoked.

**Fail signature:** no laser on any target; the code differs from the kneeboard; the laser
drops for a minute or more mid-attack; infantry lased; `AUTOLASE setup failed` in `dcs.log`.
