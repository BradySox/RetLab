### B193 — The Viper's auto countermeasures answer a lock, and CAS/SEAD flights see their working box · §74 · ☐ UNTESTED

**Setup:** a player Viper on a CAS flight. Edit Flight → DTC tab → tick Countermeasure programs. Generate and slot in.

**Pass:**
- CMDS page: the auto-program grid lists the threats, SAMs on AUTO 2, EWRs and AWACS on NONE.
- CMDS to SEMI, then let an SA-6 or similar lock you: the jet asks to dispense (AUTO: it dispenses).
- HSD: a closed box around the CAS area, tagged CAS on the DEST page, and the front line drawn.
- A SEAD flight gets the same box tagged SD; a strike gets none. With Front line unticked, the borders get its points.

**Fail signature:** the CMDS grid empty or all NONE (the jet ignored the cartridge's table); SEMI never cues; the box missing on a CAS flight with no player drawings.
