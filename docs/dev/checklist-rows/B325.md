### B325 — Fill support adds the escort and SEAD the route needs · §130 · ☐ UNTESTED

No flight needed: this is a pass in the Retribution app. Right-click an enemy target inside a
SAM ring shown on your map, add your own Strike flight, then press **Fill support** in the
package window.

**Pass:**
- A 2-ship SEAD Escort (or SEAD Sweep) is added. If the route crosses enemy fighter cover, a
  2-ship Escort is added too.
- The note lists what was added. Pressed again, it adds nothing more.
- On a CAS package the fighter cover is a TARCAP.
- A target whose route crosses no SAM ring on your map gets no SEAD, even with the fog
  overview ticked and a hidden site nearby.
- With no free SEAD jets in range, the escort is still added and the note says no SEAD was
  added.

**Fail signature:** the button stays grey after a flight is added; it adds flights on an
unthreatened route; it adds SEAD for a site you cannot see; the new flights do not show in
the package list until the window is reopened; the window errors.
