### B346 — JTAC lasing call reads in NM with an MGRS grid, one target per JTAC · ctld · ☐ UNTESTED

Any mission with a front-line JTAC drone and the CTLD plugin's JTAC autolase option on.

**Pass:**
- Each new lasing shows one Autolase message: `JTAC Alpha lasing <display name>, code ####`,
  then `BULLS ###/## NM`, then `MGRS <zone> <square> ##### #####`.
- The target name is the editor's display name (`ZSU-57-2 Sparka`), not `ZSU_57_2`.
- One JTAC lights one target at a time; when it dies, the next call names the next target.
- The bullseye call matches the F10 map's bullseye ruler within a mile; the grid matches the
  target's MGRS in the F10 map.
- F10 > Autolase status lists the same name and position.

**Fail signature:** a `km` distance, `ZSU_57_2`-style names, two calls at once from one JTAC,
or no lasing call at all (a Lua error in `dcs.log` from `ctld-config.lua`).
