### B233 — The cleaned-up plugin options reach the mission · plugin options (§14) · ☐ UNTESTED

**Pass:** on a mission generated after the 2026-10-15 plugin options audit:

- The F10 radio menu has no **SKYNET IADS RED** or **BLUE** entry.
- With **Mobile SHORAD shoot-and-scoot** ticked, an SA-8 or SA-15 that shuts down moves
  roughly 1,000 to 1,600 ft before it lights up again.
- With GPS jamming, cruise missiles or neutral border defense on in Settings, each works
  with no plugin checkbox to tick.
- On a LotATC server, blue's scope shows red SAM rings only for sites blue has engaged and
  the fixed SAM sites.

**Fail signature:** a SKYNET IADS menu appears with the debug menus unticked; a SHORAD
scoots about 1,000 to 1,600 meters (the feet were read as meters); a ticked feature does
nothing; LotATC draws a ring on a red SAM blue has never engaged.
