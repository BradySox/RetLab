### B286 — The first save of a new campaign suggests a file name · UI (Save As) · ☐ UNTESTED

Start a new campaign, then press Ctrl+S (or File > Save As).

**Pass:** the dialog opens in the Saves folder with the name box reading `<campaign name> <today's date>.retribution`, e.g. `Fulda Gap 1985 2026-10-24.retribution`; Enter saves it; a later Ctrl+S saves without a dialog; Save As afterwards shows that file's own name.

**Fail signature:** the name box is empty; the name has the wrong date or a character Windows rejects; the dialog opens in another folder.
