### B254 — Phone map over home Wi-Fi · §115 phone map · ☐ UNTESTED

**What changed (2026-10-19):** File > Phone link turns on a view-only map for a phone on
the same Wi-Fi. With the box ticked at launch the server also listens on the home network;
the dialog shows a QR code with the phone key.

**Pass:** tick the box, restart, allow the Windows firewall prompt on private networks,
load a campaign, scan the code: the phone shows the same map as the PC, with bases,
flights and threat rings. Dragging a waypoint on the phone does nothing to the PC's plan.
Untick the box: the phone's next reload is refused.

**Fail signature:** the phone cannot connect (check the firewall prompt was allowed, and the
phone is not on a guest network); the PC's map breaks with the box ticked; a change made on
the phone shows up on the PC.
