in File > Phone link and press Send test: the test arrives. Fly a mission and accept the
results: the phone gets "RetLab: turn N is ready" with the SITREP and the flight count.
With the PC offline the turn still processes.

phone is not on a guest network); the PC's map breaks with the box ticked; a change made on
the phone shows up on the PC.
